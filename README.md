## Описание

Репозиторий содержит выполненные задания по теме:
FastAPI и Pydantic

Цель: освоить валидацию данных и создание моделей с использованием Pydantic

## Структура проекта

### task1_user_registration
Базовая модель регистрации пользователя с валидацией

### task2_extended_registration
Расширенная модель (добавлены имя и телефон)

### task3_recursive_model
Рекурсивная модель для вложенных JSON-структур

## Используемые технологии
- Python 3
- FastAPI
- Pydantic

## Как запустить
pip install -r requirements.txt
python main.py

## Реализованный функционал
- Валидация username, email, password
- Проверка совпадения паролей
- Проверка возраста
- Дополнительные поля (имя, телефон)
- Рекурсивные структуры данных
