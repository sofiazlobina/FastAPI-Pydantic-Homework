## Задание 3 — Рекурсивная модель
### Условие
Создать модель для обработки вложенного JSON с произвольной глубиной.

### Пример структуры:

{
  "data": "value",
  "child": {
    "data": "value",
    "child": {
      "data": "value"
    }
  }
}

### Реализовано
- Рекурсивная модель Node
- Поддержка неограниченной вложенности
- Поле child является опциональным
- Корректная сериализация в JSON

### Запуск
python main.py
