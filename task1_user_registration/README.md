## Задание 1 — Регистрация пользователя
### Условие
Создать модель Pydantic для валидации данных пользователя.

### Реализовано
- username (3–20 символов, латиница, цифры, _)
- email (валидный формат)
- password (минимум 8 символов, цифра, регистр)
- password_confirm (совпадает с password)
- age (18–120)
- registration_date (автоматически)
 
### Запуск
python main.py
